## 1. 引言

### 1.1 目的
本文档旨在详细描述 FloydEnchantPlus 插件中“忠诚 IV”附魔的完整功能需求、触发机制、效果表现及配置参数，确保开发实现与预期设计一致。

### 1.2 适用范围
该附魔仅适用于**三叉戟（Trident）**物品。若通过命令或配置强制附加于其他物品，插件应予以忽略或发出警告。

### 1.3 术语定义
| 术语 | 定义 |
| :--- | :--- |
| **忠诚 III（Loyalty III）** | 原版 Minecraft 附魔，投掷后自动回弹至玩家手中。 |
| **忠诚 IV（Loyalty IV）** | 本插件扩展附魔，在忠诚 III 基础上增加死亡救赎与雷罚效果。 |
| **绑定玩家** | 当前持有或装备该物品的玩家。 |
| **敌方生物** | 对绑定玩家具有攻击性的生物（Hostile Mobs），包括僵尸、骷髅、苦力怕、蜘蛛、末影人、卫道士、掠夺者、尸壳、流浪者、烈焰人、岩浆怪、恶魂、潜影贝、猪灵蛮兵等，且不限于是否已激怒。**（不包含其他玩家、中立生物及被动生物）。** |
| **虚空伤害** | 指 `DamageCause.VOID` 类型，即玩家掉落至 Y < -64 或掉出世界边界所受到的伤害。 |

## 2. 总体功能描述

“忠诚 IV”附魔是原版“忠诚 III”的终极升级形态。它不仅保留了三叉戟投掷后自动返回的特性，更赋予持有者一次逆天改命的能力：

> **当持有者遭受非虚空来源的致命伤害时，三叉戟将汲取自身魔力触发“不死图腾”效果挽救持有者，并立即对周围 30 格内所有敌方生物降下持续的雷霆审判，直至威胁被彻底清除。**

该效果旨在作为玩家冒险中的终极保命底牌，拥有较长的内置冷却时间以维持服务器平衡。

## 3. 详细功能需求

### 3.1 基础继承效果（基于原版忠诚 III）
- **需求编号**：REQ-LOY-01
- **描述**：附有忠诚 IV 的三叉戟在投掷后，会以更高速度（或与原版忠诚 III 一致的速度）返回玩家手中，无视距离（超出加载范围则以物品实体形式存在，待玩家靠近后回归）。
- **兼容性**：必须与原版忠诚 III 的返回逻辑完全兼容，不发生冲突。

---

### 3.2 核心触发条件（死亡救赎前置）
- **需求编号**：REQ-LOY-02
- **触发事件**：玩家 `EntityDamageEvent` 或 `PlayerDeathEvent` 前置检测，当玩家生命值 ≤ 0 且即将进入死亡状态时。
- **持有判定**：玩家**主手（MainHand）**、**副手（OffHand）** 或 **盔甲栏（Armor slots，包括头盔、胸甲、护腿、靴子）** 中，**至少有一个槽位** 的物品包含忠诚 IV 附魔。
- **伤害类型排除（关键更新）**：若导致本次伤害的 `DamageCause` 为 **`VOID`（虚空伤害）**，则本效果**不触发**，玩家正常死亡（即使持有忠诚 IV 物品）。
- **冷却判定**：若该玩家当前处于“雷罚冷却（Cooldown）”状态，则本效果**不触发**，玩家正常死亡。

### 3.3 不死图腾效果（救赎机制）
- **需求编号**：REQ-LOY-03
- **效果触发**：满足触发条件后，插件必须**取消（Cancel）**玩家的死亡事件，将玩家生命值强制设置为 `1.0`（半颗心）。
- **状态给予**：立即为玩家施加以下状态效果（效果等级及时长参考不死图腾）：
  - 生命恢复 II（Regeneration II）—— 持续 45 秒（900 ticks）。
  - 伤害吸收 IV（Absorption IV）—— 持续 5 秒（100 ticks），提供 16 颗心（32 点）的伤害吸收生命值。
  - 清除负面效果：移除玩家身上的“着火（Fire）”状态。
- **表现反馈**：触发瞬间应在玩家位置播放不死图腾的专用动画与音效（`item.totem.use` 和对应的粒子效果）。
- **物品消耗**：**本附魔触发时，物品本身不会被消耗**。但会消耗大量的物品耐久度（详见 3.5）。

### 3.4 雷霆审判（范围打击机制）—— 核心特色
- **需求编号**：REQ-LOY-04
- **触发时机**：在成功触发不死效果（REQ-LOY-03）**之后**立即执行。
- **作用范围**：以触发效果的玩家坐标为中心，**半径 30 格**的球形范围内。
- **目标筛选**（重要）：
  - 必须是**生物实体（LivingEntity）**。
  - 必须属于**敌方生物（Hostile Mob）**类别（判定标准参考 1.3 术语定义）。
  - **必须存活（isAlive == true）**。
  - *排除对象*：不包含玩家、动物（牛、羊、猪等）、中立生物（末影人若未激怒则排除，激怒后包含）及铁傀儡、雪傀儡等。
- **打击逻辑（持续雷击）**：
  1. 对当前筛选出的每一个敌方生物，在其所在位置召唤一道**闪电（LightningBolt）**。
  2. 闪电设置为**不引起火灾（setFireTicks(0) 或不设置火焰）**，防止地形大面积烧毁。
  3. **重复判定**：建立一个循环任务（Scheduler），每隔 **1.5 秒（30 ticks）** 对范围内的敌方生物进行重新扫描。
  4. **终结条件**：循环持续进行，直到**范围内不存在任何敌方生物**（即全部死亡、传送离开或消失）。
  5. **强制熔断（防卡服）**：设置最大循环时长上限为 **20 秒**。若 20 秒后仍有怪物存活，强制终止循环（记录 Warn 日志，防止服务器卡顿）。

### 3.5 耐久度与冷却机制（平衡性约束）
- **需求编号**：REQ-LOY-05
- **耐久消耗**：触发一次效果，强制消耗该三叉戟 **150 点** 耐久度（若物品总耐久低于 150，则直接损毁消失）。
- **全局冷却**：
  - 触发效果后，绑定玩家进入 **5 分钟（300 秒）** 的冷却状态。
  - 冷却期间，该玩家持有的任意忠诚 IV 物品均无法再次触发 REQ-LOY-03 效果。
  - 冷却提示：当玩家在冷却期间再次受到致命伤时，应在聊天栏或 ActionBar 提示“§c忠诚 IV 正在冷却中...”。
- **跨世界冷却**：冷却状态不因玩家切换世界而重置。

## 4. 配置参数（config.yml）

插件需在 `config.yml` 中为该附魔提供可调节参数，以便服主按需定制。

```yaml
enchants:
  loyal_iv:
    # 是否启用该附魔
    enabled: true
    
    # 雷罚作用半径（格）
    strike_radius: 30.0
    
    # 雷击间隔（刻，20刻=1秒）
    strike_interval_ticks: 30 # 即1.5秒
    
    # 雷罚最大持续时长（秒），防止死循环
    strike_max_duration_seconds: 20
    
    # 触发后的冷却时间（秒）
    cooldown_seconds: 300
    
    # 触发时消耗的耐久度
    durability_cost: 150
    
    # 是否在触发时播放图腾动画
    play_totem_animation: true
    
    # 是否允许闪电破坏地形（建议false）
    lightning_fire_damage: false
    
    # 是否忽略虚空伤害（硬编码为true，不可配置，但保留字段说明）
    # ignore_void_damage: true  # 固定为true，不提供更改
```

## 5. 用户界面与反馈

### 5.1 附魔名称显示
- 物品提示框中，附魔名称显示为 **忠诚 IV**（支持原版颜色代码，如 §7 灰色）。
- 附魔等级必须为 4，不与原版忠诚 I-III 冲突（即物品可以单独存在忠诚 IV，也可以同时存在忠诚 III？**建议互斥**：若物品已有忠诚 III，铁砧合并升级为忠诚 IV；若附魔忠诚 IV，覆盖原版忠诚，避免重复显示）。

### 5.2 触发提示
- **全局公告（可选）**：可在配置中设置是否向全服玩家广播 `§e[!] §6[玩家名] §e触发了雷霆审判！`。
- **持有者自身提示**：触发时在 ActionBar 显示 `§dFloydEnchantPlus §f- 雷霆裁决已降临！`。

## 6. 非功能性需求

### 6.1 性能要求
- 雷电循环扫描（30格球形范围）在 20 秒内的计算量必须可控。建议采用**异步任务（Async）** 进行实体筛选，但召唤闪电必须同步到主线程（调用 `Bukkit.getScheduler().runTask`）。
- 严禁每 tick 扫描，必须遵循 1.5 秒的间隔设定。

### 6.2 兼容性
- **服务端版本**：支持 Minecraft 1.21.x 及以上版本（使用 Paper / Spigot API）。
- **附魔冲突**：必须与 **经验修补（Mending）** 共存（耐久消耗可由经验修补缓慢恢复，但触发瞬间消耗优先结算）。
- **其他插件**：不应干涉其他插件对死亡事件的监听，若其他插件取消死亡事件，本插件应能正确识别并避免重复触发（双重触发保护）。

### 6.3 日志记录
- 当触发“雷霆审判”时，在服务端日志中记录：`[FloydEnchantPlus] Player [name] triggered Loyalty IV at [world] [x, y, z], killed [count] mobs.`
- 当玩家因虚空伤害死亡且持有忠诚 IV 时，不记录特殊日志（或仅记录调试级别，但无需提示玩家）。

## 7. 测试验收标准

| 测试编号 | 测试场景 | 预期结果 |
| :--- | :--- | :--- |
| TC-01 | 玩家手持忠诚 IV 三叉戟跳入虚空（Y<-64） | **效果不触发**，玩家正常死亡（掉落物品等正常死亡流程）。 |
| TC-02 | 玩家手持三叉戟，因怪物攻击生命归零 | 玩家复活，雷罚触发，周围 30 格怪物受雷击。 |
| TC-03 | 玩家背包中有三叉戟，但未手持/装备 | 玩家正常死亡，效果不触发。 |
| TC-04 | 玩家手持三叉戟，周围 30 格有 5 只僵尸 | 玩家复活，每 1.5 秒劈一次闪电，直到 5 只僵尸全部死亡。 |
| TC-05 | 玩家触发后 10 秒再次受到致命伤 | 触发失败，提示冷却中，玩家死亡。 |
| TC-06 | 三叉戟耐久为 100 | 触发后三叉戟直接消失（耐久不足 150），但复活和雷罚依然正常执行。 |
| TC-07 | 怪物躲在 31 格处 | 怪物不受到任何闪电伤害，仅 30 格内怪物受影响。 |
| TC-08 | 玩家因 /kill 命令死亡（伤害类型自定义） | 若 /kill 产生的 DamageCause 非 VOID，则**正常触发**（除非服主有意规避，可自行调整）。 |
